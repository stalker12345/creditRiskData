# 🚀 Быстрый запуск Streamlit приложения

## Простейший способ запуска

### Вариант 1: Использовать готовый скрипт

```bash
cd "/media/user/Programs/C/Курс 4/Диплом/CreditRiskDataOld"
./run_streamlit.sh
```

При первом запуске он сам создаст `venv` и поставит зависимости, если их ещё нет.

### Вариант 2: Запуск по иконке в Linux

Откройте `creditriskdata-local.desktop` в файловом менеджере. Если система попросит разрешение на запуск, подтвердите его.

### Вариант 3: Ручной запуск

```bash
# 1. Активировать виртуальное окружение
source venv/bin/activate

# 2. Установить зависимости (если еще не установлены)
pip install -r streamlit_model/requirements_streamlit.txt

# 3. Запустить приложение
python -m streamlit run app.py
```

## 🌐 Доступ к приложению

После запуска приложение автоматически откроется в браузере по адресу:

**http://localhost:8501**

Если браузер не открылся автоматически, скопируйте адрес из терминала и вставьте в браузер.

## ⚠️ Устранение проблем

### Ошибка "Модель не найдена"
Убедитесь, что файлы находятся в `streamlit_model/`:
- model.skops
- metadata.json
- model_metrics.json
- lambdas.pkl

### Порт занят
Используйте другой порт:
```bash
streamlit run app.py --server.port 8502
```

### Зависимости не установлены
```bash
pip install --upgrade -r streamlit_model/requirements_streamlit.txt
```
