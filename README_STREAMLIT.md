# 🏦 Система оценки кредитного риска - Streamlit приложение

## 📋 Описание

Интерактивное веб-приложение для оценки кредитного риска на основе машинного обучения. Система позволяет банкам и финансовым организациям быстро оценить вероятность дефолта по кредиту на основе данных заёмщика.

## ✨ Особенности

- 🎯 **Простой интерфейс** - Интуитивно понятная форма ввода данных
- 📊 **Визуализация результатов** - Графики и метрики для наглядности
- 💼 **Бизнес-интерпретация** - Объяснение результатов простым языком
- 📈 **Подробные метрики** - Полная информация о качестве модели
- 🔍 **Анализ факторов** - Автоматическое выявление факторов риска

## 🚀 Быстрый старт

### 1. Активация виртуального окружения

Если у вас уже есть виртуальное окружение:

```bash
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

Если виртуального окружения нет, создайте его:

```bash
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
```

### 2. Установка зависимостей

```bash
pip install -r streamlit_model/requirements_streamlit.txt
```

### 3. Запуск приложения

```bash
streamlit run app.py
```

Приложение автоматически откроется в браузере по адресу: `http://localhost:8501`

## 💻 Использование

### Оценка кредитного риска

1. Откройте приложение в браузере
2. Перейдите на вкладку "🎯 Оценка риска"
3. Заполните форму данными заёмщика:
   - Личные данные (возраст, доход, статус жилья)
   - Кредитная история
   - Параметры кредита
4. Нажмите "🔍 Оценить риск"
5. Просмотрите результаты:
   - Вероятность дефолта
   - Рекомендация (одобрить/отказать)
   - Визуализация
   - Бизнес-интерпретация
   - Факторы риска

### Просмотр метрик модели

Перейдите на вкладку "📚 О метриках" для подробного объяснения:
- Accuracy, Precision, Recall
- ROC-AUC, F1-Score
- Матрица ошибок

### Информация о системе

Вкладка "ℹ️ О системе" содержит:
- Описание работы системы
- Факторы, учитываемые моделью
- Интерпретация результатов
- Технические характеристики

## 📊 Метрики модели

- **Accuracy:** 93.8% - общая точность предсказаний
- **Precision:** 95.2% - точность при отказе
- **Recall:** 75.4% - полнота поиска дефолтов
- **ROC-AUC:** 0.949 - качество ранжирования рисков
- **F1-Score:** 0.842 - баланс между точностью и полнотой

## 🔧 Устранение неполадок

### Ошибка загрузки модели

Убедитесь, что файлы модели находятся в директории `streamlit_model/`:
- `model.skops`
- `metadata.json`
- `model_metrics.json`
- `lambdas.pkl`
- `load_model.py`

Если ошибка содержит `No module named '_loss'`, значит приложение запущено на старых файлах. В этой версии в `streamlit_model/_loss.py` добавлен compatibility shim для внутренних классов scikit-learn.

### Порт уже занят

Если порт 8501 занят, используйте другой порт:

```bash
streamlit run app.py --server.port 8502
```

### Проблемы с зависимостями

Убедитесь, что все зависимости установлены:

```bash
pip install --upgrade -r streamlit_model/requirements_streamlit.txt
```
